# Fake News Detection System

A machine learning-based system that detects fake news using Natural Language Processing (NLP) techniques.

## Project Overview
This project was developed as part of the CS196 Final Project. It uses machine learning and NLP to classify news articles as real or fake.

## Features
- Real-time fake news detection
- User-friendly web interface
- Historical analysis tracking
- Machine learning model using Multinomial Naive Bayes
- Beautiful and intuitive UI

## Project Structure
- `main.py`: Streamlit web application
- `model1.py`: Machine learning model implementation
- `data.xls`: Training dataset
- `requirements.txt`: Project dependencies
- `user_logs.json`: User interaction history

## Setup Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/samarpanpoudel26/Deployed_FakeNewsDetectionSystem.git
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   streamlit run main.py
   ```
